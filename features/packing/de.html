Kostenlos im App Store und bei Google Play

So packen Sie mit SOMEWHERE

Sie müssen keine Liste aus der Notizen-App mehr mit Freunden hin- und herschicken. Tippen Sie in einer Reise auf „Packliste“, um die Checkliste für genau diese Reise zu öffnen.

  1. Basics auf einmal hinzufügen

    Tippen Sie auf „Grundausstattung hinzufügen“, um Dinge zu sehen, die oft eingepackt werden, etwa Reisepass, Handy, Powerbank und Medikamente. Behalten Sie nur, was Sie brauchen, und fügen Sie alles auf einmal hinzu. Was schon auf der Liste steht, wird nicht doppelt hinzugefügt.

  2. Alles Weitere ergänzen

    Geben Sie einen Eintrag im Feld unten ein, und er landet sofort auf der Liste. Sie können Einträge auch gruppieren, zum Beispiel Ladegerät und Reiseadapter unter „Elektronik“.

  3. Übersichtlich ordnen

    Halten Sie einen Eintrag gedrückt und ziehen Sie ihn, um die Reihenfolge zu ändern. Mit „Trennlinie hinzufügen“ teilen Sie die Einträge in eigene Karten auf, sodass Kleidung, Kulturbeutel und Dokumente leicht auseinanderzuhalten sind.

  4. Gepacktes abhaken

    Haken Sie Einträge ab, sobald sie im Koffer sind. Die Schaltfläche „Packliste“ in der Reise zeigt, wie viele Einträge Sie schon gepackt haben.

Gemeinsame und private Packliste

Es gibt zwei Listen: „Gemeinsam“ und „Privat“. Die gemeinsame Packliste sehen alle Reisepartner, die private Packliste nur Sie.

  • Gemeinsame Packliste

    Für Dinge, die nur eine Person mitbringen muss, wie Mehrfachsteckdose, Medikamente oder Snacks, damit alle sehen, ob sie schon gepackt sind

  • Private Packliste

    Für Ihre eigenen Sachen wie Reisepass, Kleidung und Kulturbeutel, auf einer Liste, die nur Sie sehen

Listen früherer Reisen wiederverwenden

Kopieren Sie einen einzelnen Eintrag oder die ganze Liste und fügen Sie sie in die Packliste einer anderen Reise ein. Wenn Sie eine Reise duplizieren, um eine ähnliche zu planen, können Sie die Packlisten gleich mitkopieren.

Häufige Fragen

Sehen meine Reisepartner meine private Packliste?

Nein, Ihre private Packliste sehen nur Sie. Reisepartner sehen nur die gemeinsame Packliste.

Wer kann die gemeinsame Packliste bearbeiten?

Reisepartner, die den Reiseplan bearbeiten dürfen, können auch auf der gemeinsamen Packliste Einträge hinzufügen und abhaken. Jeder Reisepartner kann seine eigene private Packliste bearbeiten.

Sehe ich meine Packliste auch ohne Internet?

Ja, eine Liste, die Sie schon einmal geöffnet haben, können Sie offline ansehen. Zum Hinzufügen oder Abhaken von Einträgen brauchen Sie eine Internetverbindung.
